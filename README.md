# forest-fires-ml

## Description
A machine learning project based on the UCI Forest Fires dataset. The project focuses on predicting the burned area using regression models.

## Technologies
Python
Pandas
NumPy
Scikit-learn
Matplotlib

## Methods:
Data preprocessing
Train/test split
Feature scaling with StandardScaler
Linear Regression
R² evaluation
RMSE evaluation

## So.. What I did:
Loaded and analyzed the dataset.
Selected numerical features.
Applied logarithmic transformation to the target variable.
Split the data into training and testing sets.
Standardized features.
Trained a Linear Regression model.
Evaluated the model using R² and RMSE.
