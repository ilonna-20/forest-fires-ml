# forest-fires-ml

## Description
Machine learning project for predicting forest fire risk
using the UCI Forest Fires dataset.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- AWS SageMaker

## Models
- Linear Regression
- Random Forest
- XGBoost

## What I did
- Prepared and cleaned the dataset
- Performed feature preprocessing
- Trained ML models
- Evaluated model performance
- Worked with AWS SageMaker
